# Cozmo C# SDK API Reference

This site contains the public API reference for the Cozmo C# SDK. The reference is
generated from the `Cozmo` project and its XML documentation comments.

The `Anki.Cozmo.Sdk` namespace contains the higher-level SDK API. Other `Anki.*`
namespaces contain the generated CLAD protocol types used to communicate with Cozmo's
engine.
