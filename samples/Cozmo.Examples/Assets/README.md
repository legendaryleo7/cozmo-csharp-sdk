# Example assets

These files are copied from the Python SDK's `examples/` directory so the C# ports can
reproduce the same face images and quiz questions:

- `face_images/` — `cozmosdk.png`, `hello_world.png`, `ifttt_gmail.png`,
  `ifttt_sports.png`, `ifttt_stocks.png`
- `quiz_questions.json` — questions used by the quizmaster port

repository's `LICENSE.txt`.
